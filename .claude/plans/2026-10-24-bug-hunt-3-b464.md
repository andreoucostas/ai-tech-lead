`release.ps1:623` runs `git -C $repo add -A` and never reads its exit code. `:624` then reads `diff --cached`. With

Repro: scratch clone at `a084c04d`, an empty `.git/index.lock` planted (a stale lock from a crashed git, or another
session's or the IDE's git holding it), then `release.ps1 -Version 0.98.3 -NoPush -NoEvals -ReviewEvidence ...`.
Every gate passed. Then `fatal: Unable to create '.../rel/.git/index.lock': File exists.`, `Nothing new to stage --
