## Grading (`Test-ScenarioEvidence` case `b528-options`, `.claude/evals/run-agent-evals.ps1`; main agent only)

Over every main-agent text block before the first main-agent Write, Edit, MultiEdit or NotebookEdit tool_use, both legs (B-410's
cut-off; Copilot's create, edit and apply_patch convert to Write and Edit; a subagent's text never counts):
- **OPTIONS**: one block in which `$designOpt` matches both A and B. `rec=True`: that block also has a `$designRec` line (B-410's FULL).
- **EXIT**: no OPTIONS block, and a block matches `$b528Exit`.
- **NEITHER**: otherwise. Reported: `half` (a block with one option label or a recommendation line alone, B-410's PARTIAL) and
  `doneWhen` (a Done-when label: a plan was posted).

```
$designOpt = '(?im)^\W*(?:\d+[.)]\s*)?\W*(?:option|approach)\s+([ab])\b'
$designRec = '(?im)^\W*(?:\d+[.)]\s*)?\W*recommend(?:ed|ation)?\b'
$b528Exit  = '(?im)\bno\s+(?:real|meaningful|viable|genuine|sensible|reasonable|other|design)\s+(?:design\s+)?alternatives?\b|\bonly\s+one\s+(?:(?:real|sensible|reasonable|viable|obvious)\s+)?(?:design|approach|option)\b'
```

## Readings and decision rule (per host; k of 6 valid runs a cell; hosts side by side, never pooled)

- **NOT REPRODUCED**: C OPTIONS in 4 or more. The agent follows §2 on this fixture and host; neither R1 nor R2 is shown here.
- **R1**: C EXIT in 4 or more. The agent takes the exit and the field script missed it: B-528 closes as not a miss on that host.
- **R2**: C NEITHER in 4 or more, and T OPTIONS at least C OPTIONS + 3. The options rule is skipped and the reminder's wording fixes
  it: the T line becomes a guarded shipping change (the router in all three dists, CHANGELOG), filed as its own next step, not done
  here.
- **R2-UNFIXED**: C NEITHER in 4 or more, and T OPTIONS at most C OPTIONS + 2: skipped, not fixed by this wording at this n; B-528
  stays open and the next candidate is the maintainer's.
- **NOT SETTLED**: any other split, or a cell short of 6 valid runs (a stop included).
- Across hosts: B-528 closes on R1 on both hosts, or R1 on Copilot with NOT REPRODUCED on Claude Code. Any R2 files the shipping
  change; Copilot's decides alone, as the field ran on Copilot's runtime. Otherwise B-528 stays open with both readings and the
  maintainer decides. Reported, not readings: T against C where C is at ceiling, `gate` per cell, how many NEITHER runs posted a
  plan (`doneWhen`), and T's cost against C's by medians.
