## G1. guard.ps1 (guarded, step 4)

### 1. The credential exemption reads every segment of the absolute path, so a checkout under a test-named folder disables the check — CONFIRMED, both hosts, secret-leak class
`guard.ps1:213-223` splits `$fp` as given and exempts the write when any segment is a whole-token `test|spec|mock|
fixture|example|sample|development` or a PascalCase `*Tests` affix. Claude Code sends `file_path` absolute, so a
repository at `C:\Development\repo`, `C:\Projects\test\repo`, `D:\Projects\samples\shop`, `C:\Mocks\repo` or a worktree

hosts; the same content under `C:\repo\...` exits 2. An `apply_patch` section whose `Add File:` path is absolute does
the same (Copilot shape, no deny JSON).
Fix: make the path repository-relative before segmenting. The repository is the hook's own `..\..` (as audit-trail
and route-prompt find it); resolve a relative `$fp` against it, `[IO.Path]::GetFullPath`, strip the root prefix
ordinal-ignore-case, and scan only the remainder; a path outside the root gets no exemption. Red cases in
`fixtures/guard-cases.ps1`: `f='C:\Projects\test\repo\src\AuthService.cs'` with the credential content `block=$true`,
and the same under a folder named `Development`. Keep `tests/AuthServiceTests.cs` and `src/Api.UnitTests/...` allowed
(cases 135-138).

### 3. The connection-string credential regex is quadratic on an unclosed quote: 280 KB takes 108 s on 5.1 — CONFIRMED, stall and timeout false green
`guard.ps1:241` alternatives 2 and 3 (`connectionstring["' ]*[:=]\s*["'][^"']*(?:password|pwd)...[^"']*["']`): the
unanchored `[^"']*` is retried from every `password=` and each retry rescans to the end for a closing quote.
A C# line opening a connection-string literal (`var connectionString = "`, never closed) followed by the password key, `=`, four letters and `;` repeated 10000 times (140 KB): pwsh 1.4 s, 5.1 27 s; ×20000 (280 KB): pwsh 4.2 s,
5.1 108 s; ×40000 (560 KB): pwsh 17.6 s. Copilot's `hooks.json` times out at 10 s, Claude Code at 60 s, so the
write is allowed. A 3.3 MB clean file takes under 3.2 s on both hosts: the shape, not the size.
Fix: bound both `[^"']*` in alternatives 2 and 3 to `[^"']{0,2000}`, and `guard.ps1:250`'s entry `[^"]*` likewise
(a connection string is shorter). Red case: a Guard.Tests case that runs the hook on the ×40000 payload through
`Start-Process` with `WaitForExit(15000)` and kills it on timeout, asserting it decided inside 10 s (the harness's
`Invoke-Hook` has no timeout, so the unfixed 5.1 run would otherwise take minutes).

### 4. `[Fact(`/`[Theory(` Skip pattern is quadratic on unclosed parentheses: 160 KB takes 26 s on pwsh — CONFIRMED
`guard.ps1:161` `\[(Fact|Theory)\([^)]*Skip\s*=`: `[^)]*` spans newlines and is rescanned from every `[Fact(`.
`[Fact(\n`×5000 (40 KB): pwsh 2.1 s, 5.1 3.7 s; ×20000 (160 KB): pwsh 26 s. Distinct from B-373 (the `[Ignore]`
