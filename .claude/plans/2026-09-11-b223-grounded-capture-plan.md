## 3. Proportionality and candidate choice

Consider these options in order, preserving WSD-074's broad discovery and existing ownership model:

1. **Keep the product unchanged.** Existing PR review and retained failures remain the controls if
   no concrete operational gap or proportionate candidate emerges.
2. **Preserve qualification in descriptions and INDEX.** This is the smallest identifiable capture
   boundary to examine. It targets the first table row only, and must not be sold as fixing false
   bodies, handoff grounding or general capture quality.
3. **Reshape proposition construction before rendering.** Consider only if diagnosis identifies an
   additional operational change beyond existing grounding instructions that reaches a named body
   failure. Do not combine it with a handoff repair and then credit the mixture as one mechanism.

Do not add an automatic critic, truth checker, evidence registry, new schema, approval queue, general
harness or global instruction. A separate absence-evidence rule would restate current verification
requirements; no claim count shows that addition to be effective or cheap. Textual diagnosis
can select a candidate, but it cannot establish behavioral improvement or authorize shipping it.

The initial candidate sketch for option 2 is a replacement inside the existing wiki draft/index
steps: **derive a description no stronger than the body's scoped claim and explicit uncertainty;
reuse that description in INDEX.** Reusing the description is already implicit in the index syntax;
the added operational distinction is preserving the body's qualifications while summarising it.
This sketch is not a locked implementation. The attempt must produce exact before/after prose and
byte counts, identify which existing sentences disappear, and justify each changed carrier.
